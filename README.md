# 声阶 · Ear Training

一个完全在浏览器本地运行、可深度配置的练耳训练应用。音程辨认与和弦进行使用各自独立的配置和出题模型。

## 快速开始

最简单的方式是直接打开 `dist/index.html`。

如果浏览器限制本地文件的部分功能，可在项目目录运行：

```powershell
py -m http.server 4173 -d dist
```

然后访问 `http://127.0.0.1:4173/`。

## 当前功能

- 音程辨认：固定或随机起始音，范围从小二度扩展到双八度，不引入调性或离调概念
- 和弦进行：每轮选择大调或小调及调性中心，由系统逐个和弦生成完整题目
- 常见进行热身：直接轮换高频大调/小调进行，不混入随机和声
- 可手动加入三级属、重属、降二级属、那不勒斯六和弦、德国增六和弦等调外和声
- 三档难度与 10/15/20 题配置；难度会调整音程预设与答案干扰项数量
- 钢琴、吉他、萨克斯、小提琴四种实时合成音色
- Web Audio 实时生成题目，不依赖外部音频文件
- 每轮实时记录准确率、连续答对、用时与反应速度
- 合并式学习档案：历史记录、筛选、趋势图、综合评分与训练建议
- 能力报告打印或保存为 PDF
- 响应式界面与数字键、空格键快捷操作

## 数据说明

训练历史保存在当前浏览器的本地存储中，不会上传到服务器。换电脑或清除浏览器数据前，可在“历史”页面导出 JSON 备份。
