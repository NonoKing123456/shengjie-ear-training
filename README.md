# 声阶 · Ear Training

一个完全在浏览器本地运行、可深度配置的练耳训练应用。先选择训练材料、调性、离调内容与音色，再进入独立测试。

## 快速开始

最简单的方式是直接打开 `dist/index.html`。

如果浏览器限制本地文件的部分功能，可在项目目录运行：

```powershell
py -m http.server 4173 -d dist
```

然后访问 `http://127.0.0.1:4173/`。

## 当前功能

- 配置式训练主页：音程或和弦进行、三档难度、10/15/20 题
- 12 个调性自由多选，并可精确选择音程和功能进行题库
- 可选调外音级、借用和弦与副属和弦
- 钢琴、吉他、萨克斯、小提琴四种实时合成音色
- Web Audio 实时生成题目，不依赖外部音频文件
- 每轮 10 题，记录准确率、连续答对、用时与反应速度
- 合并式学习档案：历史记录、筛选、趋势图、综合评分与训练建议
- 能力报告打印或保存为 PDF
- 响应式界面与数字键、空格键快捷操作

## 数据说明

训练历史保存在当前浏览器的本地存储中，不会上传到服务器。换电脑或清除浏览器数据前，可在“历史”页面导出 JSON 备份。

```text
dist/
```
