# 声阶 · Ear Training

一个完全在浏览器本地运行的练耳训练应用。目前包含音程辨认、和弦进行辨认、实时计分、历史趋势与综合能力报告。

## 快速开始

最简单的方式是直接打开 `dist/index.html`。

如果浏览器限制本地文件的部分功能，可在项目目录运行：

```powershell
py -m http.server 4173 -d dist
```

然后访问 `http://127.0.0.1:4173/`。

## 当前功能

- 音程辨认：基础、标准、进阶三种题目范围
- 和弦进行辨认：常见流行、古典与爵士功能进行
- Web Audio 实时合成题目，不依赖外部音频文件
- 每轮 10 题，记录准确率、连续答对、用时与反应速度
- 历史记录、筛选、趋势图和 JSON 数据导出
- 综合能力评分、分项能力与个性化训练建议
- 能力报告打印或保存为 PDF
- 响应式界面与数字键、空格键快捷操作

## 数据说明

训练历史保存在当前浏览器的本地存储中，不会上传到服务器。换电脑或清除浏览器数据前，可在“历史”页面导出 JSON 备份。
