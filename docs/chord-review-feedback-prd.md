# 和弦答题反馈改版需求文档

## 1. 背景

当前和弦答题后的反馈区域会把正确进行中的每个和弦以独立的大卡片和五线谱展示，页面纵向高度过长。用户难以快速定位自己错在哪个和弦，也缺少直接试听错误和弦的方式。

本次改版将反馈区域调整为“结果摘要 + 双轨对照 + 集中播放控制”，让用户先看到差异，再分别试听正确答案和自己的答案。

## 2. 目标

- 缩短答题反馈区域的纵向高度，减少连续滚动。
- 清晰展示正确答案与用户答案的对应关系。
- 直接标记发生差异的和弦位置。
- 支持整段试听、单个和弦试听和 A/B 对比试听。
- 保留现有五线谱、声部连接和答后进入下一题的能力。

## 3. 范围

### 本期包含

- 和弦反馈摘要改版。
- 正确答案与用户答案的双轨对照。
- 差异和弦高亮和自动定位。
- 正确答案、用户答案、单个和弦、A/B 对比播放。
- 紧凑的整段五线谱展示。
- 反馈区的“下一题”操作。

### 本期不包含

- 修改题目生成规则。
- 修改和弦 voicing 规则或音色采样。
- 新增云端同步、账号或训练数据结构。
- 修改训练配置页和历史报告页。

## 4. 用户流程

1. 用户提交和弦答案。
2. 页面显示答题结果、我的答案和正确答案。
3. 系统比较两条进行，标记所有不同的位置。
4. 若存在错误，默认展开并定位第一个不同的和弦。
5. 用户可播放正确答案、我的答案或 A/B 对比。
6. 用户可点击任意和弦，单独试听该位置。
7. 用户点击“下一题”继续训练。

## 5. 页面结构

### 5.1 结果摘要

显示以下信息：

- 结果状态：`正确` 或 `答错了`。
- 我的答案：完整和弦进行。
- 正确答案：完整和弦进行。
- 题号和训练进度，例如 `5 / 20`。

答错时，摘要中应直接标出差异位置。例如：

```text
正确答案：Cmaj7 → Dm7 → G7 → Cmaj7
我的答案：Cmaj7 → Dm7 → Bm7♭5 → Cmaj7
                              ↑ 第 3 个和弦不同
```

### 5.2 双轨和弦对照

正确答案和用户答案上下排列，和弦位置必须一一对齐。

```text
正确答案  Cmaj7   Dm7   G7       Cmaj7
我的答案  Cmaj7   Dm7   Bm7♭5    Cmaj7
```

每个和弦节点支持点击试听。相同和弦降低视觉强调，不同和弦重点突出。

### 5.3 整段五线谱

- 默认显示一张紧凑的整段五线谱。
- 和弦符号显示在对应位置上方。
- 正确答案与用户答案可以采用上下两条谱面，或在同一谱面中用明确颜色区分。
- 错误位置必须与双轨和弦对照保持横向对齐。
- 详细单和弦谱面默认折叠，仅在用户点击和弦节点后展开。

### 5.4 播放控制

提供集中播放控制：

- `播放正确答案`：播放完整正确进行。
- `播放我的答案`：播放完整用户选择的进行。
- `A/B 对比`：播放正确进行，短暂停顿后播放用户进行。
- 单个和弦播放：点击任意和弦节点后，只播放该位置的和弦。

播放时需要同步显示当前状态，例如：

```text
正在听：我的答案 · 第 3 个和弦
```

同一时间只允许一个播放任务处于激活状态。重新点击其他播放按钮时，应停止当前播放并切换到新的播放任务。

### 5.5 下一题

- “下一题”按钮固定在反馈区底部或右下角。
- 播放进行中点击下一题时，应先停止当前播放，再进入下一题。
- 进入下一题后清除上一题的展开状态和播放状态。

## 6. 视觉规则

- 正确答案使用青绿色或绿色强调。
- 用户答案使用珊瑚红或橙红色强调。
- 当前播放和当前选中项使用荧光绿外框或明显播放状态。
- 相同和弦使用低对比度样式，避免信息噪音。
- 差异和弦必须同时在摘要、双轨对照和五线谱中保持一致的高亮语义。
- 避免每个和弦重复使用大尺寸独立卡片。
- 桌面端优先采用横向对照；移动端允许双轨折行，但必须保持位置顺序清晰。

## 7. 数据与逻辑要求

- 继续使用当前题目的正确进行和用户选择的进行数据。
- 按和弦位置比较两条进行，记录所有差异索引。
- 两条进行长度不一致时，使用“缺少”和“多出”状态展示，不得静默错位。
- 不改变现有训练历史的数据格式。
- 不改变现有音频采样和 voicing 生成逻辑。

## 8. 异常情况

- 用户答案与正确答案完全一致：不显示错误差异区，保留正确答案和整段试听。
- 用户答案长度不同：明确显示缺少或多出的和弦位置。
- 音频尚未加载：播放按钮进入不可用状态，并显示已有的音频加载提示。
- 快速连续点击播放：只保留最后一次播放请求，避免多个音频同时响起。
- 移动端宽度不足：和弦节点允许横向滚动或折行，但不能裁切和弦名称。

## 9. 验收标准

- 答错后，用户能在首屏看到完整的正确答案和用户答案。
- 用户能明确知道第几个和弦不同。
- 用户能单独试听正确答案中的任意和弦。
- 用户能单独试听自己答案中的任意和弦。
- 用户能一键完成正确答案与用户答案的 A/B 对比试听。
- 播放时能看到当前播放对象和和弦位置。
- 反馈区域相比当前版本明显减少纵向占用，不再默认展示多张超大和弦卡片。
- “下一题”在桌面端和移动端都容易找到。
- 现有音程训练、普通和弦训练、爵士题目生成和历史记录功能不受影响。

## 10. 实现提示

建议优先复用现有反馈区、爵士复盘组件、五线谱渲染和音频播放函数，先完成信息架构和交互状态，再调整尺寸与响应式样式。实现后应至少验证：正确答题、单个和弦答错、多个和弦答错、进行长度不同、A/B 播放和移动端布局。
