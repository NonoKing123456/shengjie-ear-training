# 和弦听辨答题页：调性优先与简洁播放舞台需求

## 1. 设计结论

和弦听辨答题页应让用户先确认当前调性，再进入试听和答题。调性是相对音高学习者判断和弦功能的重要参照，但不应被设计成额外的侧栏、按钮组或复杂说明。

最终页面采用以下顺序：

```text
训练标签与题号
→ 居中的当前调性
→ 简洁的大型播放舞台
→ 答案选项
```

## 2. 目标

- 让当前调性成为用户进入每题时首先确认的信息。
- 保留原有播放区直观、容易点击的视觉引导。
- 删除与答题无关或重复的文字、按钮和装饰模块。
- 保持页面在桌面端和移动端都具有明确的视觉层级。

## 3. 页面结构

### 3.1 顶部训练信息

顶部只保留两类低强调信息：

- 左侧：训练标签，例如 `TRADITIONAL JAZZ · 基础包`。
- 右侧：本题进度，例如 `1 / 10`。

训练标签与进度不得抢占当前调性和播放舞台的视觉优先级。

### 3.2 当前调性

当前调性显示在播放舞台正上方，且与播放按钮共用页面中轴线。

示例：

```text
D 大调
```

要求：

- 使用中等偏大的字号和产品主强调色（当前为荧光绿）。
- 仅显示调性名称，不追加“本题调性中心”“2 个升号”等辅助文字。
- 不使用卡片、边框、侧栏徽章、升降号板块或额外图标。
- 不放在页面左侧，避免打破播放区域的对称与平衡。

## 4. 播放舞台

播放舞台是页面最主要的交互和图形化区域。

### 4.1 布局

- 位于居中调性文字下方。
- 桌面端建议高度约 `210px`，宽度占主内容区域。
- 使用深色底、细边框和低对比度横向谱线作为背景。
- 中央保留当前的方圆角播放卡片样式，不改为大尺寸圆形播放按钮。
- 播放卡片包含现有的播放图标、`点击重听题目` 和可选的低强调辅助文字；整体视觉样式以现有实现为准。
- 点击区域应覆盖整个播放舞台，而不仅是中央播放卡片。
- 右上角可保留弱化的 `LISTEN / REPLAY` 文字作为装饰性定位，但不得影响主操作。

### 4.2 交互

- 首次播放前和重听状态均通过中央播放按钮完成。
- 点击舞台空白区域也应触发播放。
- 播放中，中央播放卡片可出现轻微边框变亮或播放图标切换；动画必须克制。
- 支持空格键重听，但不需要在页面中常驻显示快捷键说明。

### 4.3 明确不使用的元素

- 不使用声波柱、节拍点、粒子效果或循环动态图形。
- 不使用钢琴图片、波形图或其他具象背景图。
- 不增加“听主音”“听 I 级和弦”等额外播放按钮。
- 不使用装饰性的大量文字说明。

## 5. 答案区域

播放舞台下方直接进入答题区：

```text
选择你听到的进行
```

每个选项只显示序号和和弦进行，例如：

```text
1  Gmaj7 – Em7 – A7
2  Gmaj7 – F#m7 – A7
3  Dmaj7 – F#m7 – A7
4  Dmaj7 – Gmaj7 – A7
```

要求：

- 不在每个选项中重复显示“传统爵士”等模式名称。
- 选项采用清晰、完整的横向点击行；序号与和弦进行易于扫描。
- 保留现有数字键答题能力。
- 选中、正确、错误状态使用现有产品颜色语义。

## 6. 视觉层级

从强到弱依次为：

1. 中央播放卡片与播放舞台。
2. 当前调性，例如 `D 大调`。
3. 和弦答案选项。
4. 题号进度与训练标签。

页面避免出现多个同等级的大按钮或并列卡片。当前调性提供判断前提，播放舞台引导当前动作，答案区承接选择。

## 7. 响应式要求

- 移动端仍保持“训练标签/进度 → 当前调性 → 播放舞台 → 答案”的顺序。
- 当前调性和播放按钮始终居中。
- 播放舞台不能因屏幕变窄而缩小到难以点击，建议最小高度 `185px`。
- 答案行在移动端保持单列与充分点击面积。

## 8. 验收标准

- 当前调性在答题页首屏清晰可见，且位于播放舞台正上方并居中。
- 页面不存在左侧调性徽章、升降号说明块、主音试听按钮或 I 级和弦试听按钮。
- 播放舞台是首屏中最大的图形化和交互性区域。
- 播放舞台仅使用克制的横向谱线背景、现有方圆角中央播放卡片和少量文案。
- 页面不存在声波、节拍点、粒子、钢琴图片或大面积动态图形。
- 答案选项只展示序号与和弦进行，不重复模式名称。
- 页面中的主要操作只有试听题目与选择答案，不形成复杂的控制面板。
- 现有音频播放、题目生成、键盘快捷键、计时、进度和答题状态功能不受影响。

## 9. 实现提示

优先调整答题页的标题区、播放舞台和答案选项的 DOM 结构与样式。复用当前播放逻辑、键盘事件和题目数据，不改变和声生成、采样加载或训练记录的数据结构。
