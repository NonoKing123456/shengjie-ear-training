# 旋律听写：谱面输入体验改进需求

## 1. 背景

旋律听写的核心能力已经完成：首音预置、用户在五线谱中输入后续音符、试听与提交答案。但当前输入界面存在三项影响体验的问题：

- 左下角出现大量说明文字与操作按钮，抢占谱面空间，像调试面板。
- 鼠标输入时使用十字准星，容易遮挡谱线、音符和输入位置。
- 每次点击输入新音符后页面会自动滚动到顶部，严重打断连续听写。

本需求只改进输入体验，不改变旋律题目生成、音频数据、答题判定和训练记录。

## 2. 目标

- 让用户以自然、清晰的方式在五线谱上预览并输入音符。
- 让五线谱成为输入区唯一的视觉重点。
- 将输入后的页面位置保持稳定，避免任何非用户主动的滚动。

## 3. 功能一：预选音符输入

### 3.1 交互方式

- 用户移动鼠标进入当前待填写节拍格时，显示一个半透明的预选音符。
- 不使用十字准星、十字辅助线或覆盖谱面的定位线。
- 鼠标保持普通箭头指针。
- 预选音符的横向位置以鼠标指针尖端为锚点，提供直接“在此处落音”的感受。
- 预选音符的纵向位置自动吸附到最近的合法谱线或线间。
- 预览显示必要的音符头和符干；超出五线谱上下边界时，随音符显示短辅助线以标明音高，不显示测量线、网格或坐标提示。

### 3.2 正式落音

- 用户点击后，预选音符进入当前预设节拍格的正式横向位置。
- 正式音符必须与其他节拍格对齐，保持固定节奏的谱面间距。
- 从预选位置到正式位置可以使用极短、克制的过渡动画，或直接落位。
- 音符写入后，系统自动将当前待填写焦点推进到下一个空节拍格。

### 3.3 状态表达

- 预选音符：青绿色半透明。
- 已输入音符：正常白色。
- 当前待填写格：保留低对比度背景高亮或细边框。
- 当前格高亮与鼠标悬停提示使用同一节拍格矩形及相同高度；鼠标进入当前格时不叠加第二个框。
- 点击任一后续节拍格矩形内的任意高度都可切换当前格；鼠标高度超出合法音域时，预览和落音吸附到最近的合法音高。
- 首音：沿用首音预置状态，不可编辑。
- 超出所选音域或当前谱表范围的鼠标高度吸附到最近的合法音高，不写入超范围音；鼠标经过正在编辑的已填符头时，预览也保持连续。

### 3.4 移动端

- 移动端不显示鼠标悬停预览。
- 用户首次点按时显示预选音符；再次点按相同位置确认写入。
- 预览状态需要有清楚但不遮挡谱面的颜色或边框提示。

## 4. 功能二：清理输入区冗余文字与按钮

### 4.1 删除内容

从输入区删除以下常驻内容：

- `YOUR SCORE` 标签；
- `从首音继续写下旋律` 标题；
- `点击亮亮节拍格输入；点击音符试听，点击谱面空白处试听已填旋律。` 等长说明；
- 常驻的 `试听已填旋律` 按钮；
- 常驻的 `撤销上一个音` 按钮；
- 常驻的 `清空已填音符` 按钮。

### 4.2 保留的信息

输入区只保留必要信息：

- 当前旋律环境或调性，例如 `G 大调`；
- 填写进度，例如 `1 / 5 音`；
- 可编辑五线谱；
- `提交答案`主按钮。

### 4.3 替代交互

- 用户点击已填写的最后一个音符可删除该音符。
- 用户点击已填写的其他音符可进入替换状态，再次点击目标高度完成替换。
- 用户点击已填写旋律的谱面空白区域，可播放当前已填旋律。输入页点击已填音符仅用于编辑或删除，不播放单音，也不显示绿色圆形悬停框；答后复盘仍可点击单音试听。
- 在含调外音或无调性模式，高亮格为空时可先选 ♭、♮ 或 ♯，随后输入的音使用该记号；高亮格已有音时，点击记号直接修改该音。记号跟随高亮格，完成输入后不继续作用于下一格。
- 如实现上必须保留撤销能力，只允许使用一个低强调的回退图标，置于谱面右上角，并且仅在至少填写一个音符后出现。
- `提交答案`是输入区唯一的强主按钮；所有待填节拍格完成前必须禁用。

## 5. 功能三：输入后保持页面位置

### 5.1 问题定义

用户每次点击输入新音符后，页面自动滚动回顶部。此行为必须彻底消除。

### 5.2 行为要求

- 输入、替换、删除或试听音符后，浏览器窗口的垂直滚动位置不得变化。
- 如果五线谱位于独立滚动容器内，该容器的横向与纵向滚动位置也不得变化。
- 只有用户主动滚动、点击锚点导航或在移动端调出系统键盘时，页面位置才允许变化。
- 填写下一个节拍格时，不得使用会将页面滚动到元素顶部的自动聚焦逻辑。

### 5.3 实现约束

- 不得因输入一个音符而重新挂载整页、重建训练视图或替换外层答题容器。
- 不得调用会触发滚动的 `focus()`、`scrollIntoView()` 或默认锚点跳转行为。
- 渲染谱面前应保存窗口 `scrollY`；若更新过程可能改变页面位置，渲染后必须恢复该位置。
- 独立谱面容器存在滚动条时，应同时保存和恢复其 `scrollTop` 与 `scrollLeft`。
- 点击输入事件必须阻止表单提交、链接跳转和其他浏览器默认滚动行为。
- “提交答案”是唯一会主动将复盘面板定位到视口顶部的输入阶段操作；预览、落音、修改、删除和试听均不得触发该定位。

## 6. 验收标准

- 鼠标进入当前待填位置时，用户看到半透明预选音符，不看到十字光标或十字辅助线。
- 鼠标在当前节拍格矩形内上下移动，包括上下边缘与已有符头位置，预选音符持续可见；点击边缘可输入吸附后的合法音高。
- 预选音符纵向吸附到合法谱线或线间，横向以鼠标尖端为视觉锚点。
- 点击后，正式音符自动对齐到当前节拍格，并进入下一待填位置。
- 输入区不再出现 `YOUR SCORE`、长操作说明和三枚常驻辅助按钮。
- 用户可通过谱面完成已填旋律试听、最后一音删除和已填音替换；单音试听只保留在答后复盘。
- `提交答案`是输入区唯一的强主按钮。
- 连续输入至少五个音符后，浏览器页面和谱面容器均保持用户输入前的滚动位置。
- 鼠标与移动端输入均不遮挡或显著干扰谱面可读性。
- 现有首音预置、旋律环境、音域限制、提交判定、答后反馈和训练记录功能保持可用。

## 7. 实现提示

应将“谱面绘制数据更新”和“训练页面 DOM 生命周期”解耦。更新某个音符时，仅更新谱面内容与局部状态，不要重建整个答题视图。预选音符建议作为独立渲染层，与正式音符层分离，便于在鼠标移动时快速更新且不影响已输入音符。

## 8. 实现与验收记录

- 输入区只保留进度、谱面和提交按钮；含调外音与无调性模式在选中音符后显示精简的升降号控件，以保留完整音高输入能力。
- 预选层使用半透明青绿色符头与符干，超出谱表时补齐短辅助线；横向跟随鼠标尖端、纵向吸附到合法谱线或线间。正式音符仍交由 VexFlow 对齐排版。输入区使用普通箭头指针。
- 点击最后一个已填音符删除它；点击其他已填音符进入替换状态，不触发单音播放或绿色圆框。谱面空白处仍可试听已填旋律。
- 每次输入只重绘内部谱面与局部状态，并保存、恢复窗口和谱面容器滚动位置；不重新挂载训练视图。
- 窄屏下保持节拍格的可点按宽度，只有谱面容器允许横向滚动，整页不产生横向滚动；写音后保留谱面已滚动的位置。
- 升降号控件始终指向当前高亮格：空格先选后写，已填格直接改音；落音后清除预选记号，避免误应用到下一格。
- 无调性谱面按同一小节的临时记号规则处理：同音名且同八度后续自动继承升、降或还原，谱面不重复标记；不同八度不继承，修改前面的音会同步更新后续未手动指定记号的音。
