# 常见问题

[返回首页](../README.md) · [开发文档](DEVELOPMENT.md)

## 首次训练没有声音

点击训练或试听以启动浏览器音频，检查页面及系统是否静音。使用本地 HTTP 服务比较，不只测试 file://。

## 打开页面后部分功能异常

当前代码直接在 dist，可用 Python 本地服务访问，不需要 npm build。确认采样和 vendor 文件随完整仓库一起保留。

## 历史记录不见了

记录属于当前浏览器及源地址。换浏览器、端口、域名或清理存储后可能看不到原记录，先从原环境导出 JSON 再迁移。

## 旋律听写是否包含自由节奏

当前设置明确使用等时值四分音符，并给出首音，主要训练音高序列；不承诺任意节奏听写。

## 传统爵士和风格语汇包有什么区别

它们是独立配置和出题入口，记录也可能按不同类别统计。反馈时说明入口、调性、语汇包和配位设置。

## 仍无法解决

提交 Issue 时附版本或提交、系统环境、复现步骤与脱敏错误。优先提供合成文件，保留原数据与完整日志的本机备份。
