# 和弦进行模块：流行、爵士、古典风格包整合需求

## 1. 背景

当前设置页把“综合和弦”和“传统爵士”列为两个训练内容入口。综合和弦包含随机和声与一个混合了流行、古典、爵士名称的常见进行热身库；爵士使用独立的和声语汇、题目生成、配位和谱面复盘。用户希望把它们归到同一个“和弦进行”模块，进入模块后明确选择流行、爵士或古典中的一个风格包。

本次整合的重点是统一入口与训练体验，同时保证每个包在和弦语汇、命名、连接规则和实际音响上保持自身风格。风格包是用户手动选择的训练范围，系统不根据答题表现自动更换。

## 2. 目标

- 训练内容只展示一个“和弦进行”入口。
- 进入和弦进行配置后，用户从“流行 / 爵士 / 古典”中单选一个风格包。
- 三个包共用配置页结构、听题页、选项交互、答后谱面对照、播放、下一题和本轮进度。
- 题目与干扰项严格遵守所选风格包的和弦语汇及连接规则。
- 答题页使用与当前风格相符的和弦名称或功能标记；显示内容与实际播放音符一致。
- 历史训练记录继续可读，新的记录可以按风格包筛选和统计。

## 3. 范围与非目标

### 本期范围

- 合并“综合和弦”和“传统爵士”的顶层入口。
- 增加互斥的风格包选择。
- 保留爵士包内部的基础、进阶、高级语汇选择及现有配位设置。
- 将现有混合热身库按风格拆分或归属，不能继续跨风格抽题。
- 为流行包和古典包定义各自可用的题目材料、答案命名和实际配位。
- 统一训练题目交给页面、播放和复盘的基础数据格式。
- 兼容既有训练历史。

### 非目标

- 不提供多个风格包同时勾选或在同一轮中混合出题。
- 不根据用户错误自动推荐或切换风格包。
- 不在本次整合中重做音程辨认和旋律听写。
- 不为了统一代码而抹平三个风格的音乐规则或强行使用同一种 voicing。

## 4. 用户流程

```text
选择“和弦进行”
→ 单选“流行 / 爵士 / 古典”
→ 设置该风格适用的调式、调性、语汇及配位等选项
→ 选择音色与题量
→ 听题并选择和弦进行
→ 查看正确答案与自己的答案的谱面对照，可点击试听
→ 手动进入下一题
```

切换风格包时，只显示该包适用的专属设置。用户切回此前风格时，可恢复其上次选择，但本轮训练只采用开始时选定风格的配置快照。

## 5. 配置页要求

### 5.1 顶层选择

训练内容保留“音程辨认 / 和弦进行 / 旋律听写”等入口，不再把“传统爵士”作为与“和弦进行”并列的顶层入口。

选择“和弦进行”后显示：

```text
风格包（单选）
○ 流行   ○ 爵士   ○ 古典
```

每个包用一句话说明音乐材料，不使用“基础 / 标准 / 进阶”来代替风格区别。

### 5.2 共用设置

- 大调或小调。
- 可选调性中心；每题只使用本轮选中的调性。
- 题量和音色。
- 各包均沿用相同的开始训练、重听、选择答案与下一题流程。

### 5.3 专属设置

- 流行包：只显示流行语汇相关选项；如保留“随机生成 / 常见进行热身”，两者都只能使用流行包材料。
- 爵士包：保留现有基础、进阶、高级语汇包和 Shell / 训练型 / Rootless 配位选项。内部语汇包可叠加，但顶层风格仍只能选爵士。
- 古典包：只显示古典语汇相关选项，例如调内功能与受控的调外和声。现有那不勒斯六和弦、德国增六和弦等古典术语只能出现在古典包中。
- 古典包增加互斥的“键盘配位 / SATB 四声部”选择；爵士包沿用现有 Shell / 训练型 / Rootless 配位，流行包保持自己的配位规则。
- 不适用于当前风格的设置必须隐藏、禁用且不得参与出题。

## 6. 各风格包的音乐边界

| 风格包 | 首期训练材料 | 答案显示语言 | 实际音响要求 |
|---|---|---|---|
| 流行 | 常见流行循环、调内三和弦及明确的常用色彩 | 优先显示实际和弦名，必要时辅以级数 | 使用适合流行听辨的稳定配位；同一题保持统一音色与节奏 |
| 爵士 | 现有基础/进阶/高级语汇及功能连接 | 实际爵士和弦符号，罗马数字仅作可选辅助 | 沿用现有逐段优化的爵士配位与声部连接 |
| 古典 | 调内功能、转位、终止及经明确规则允许的调外功能 | 功能标记与转位信息；谱面对应真实发声音符 | 使用能体现低音、转位与声部进行的配位 |

以上是风格边界，不代表只替换显示字符串。出题、干扰项和配位必须基于同一个包的数据与规则。古典包目前尚无完整独立生成器，应作为本次新增能力设计和验证，不能直接把现有综合和弦更名为“古典”。

## 7. 题目生成与干扰项

- 每道题先确定风格包，再调用该包的语汇、连接规则、命名和配位能力。
- 正确项与干扰项必须全部属于当前风格包，并遵守所选调式、调性与专属设置。
- 干扰项应与正确项保持相同的和弦数，并在该风格内构成可解释、可实际播放的进行；不能靠跨风格名称制造明显错误选项。
- 同一道题所有选项应遵循一致的命名体系和显示粒度，不能一个选项用罗马数字、另一个用实际和弦名。
- 正确项与每个干扰项都必须有可播放音符和可渲染谱面；答后“我的答案”不得临时退化为另一种音响。
- 每题保存最终采用的音高与配位，重听原题时复现同一音响，不重新随机生成。
- 系统只在用户选定边界内随机生成，不根据用户表现自行换包或添加语汇。

## 8. 共用题目与页面接口

三个风格包应向训练页面提供一致的题目字段，至少包括：

- `stylePack`：`pop`、`jazz` 或 `classical`。
- `key`、`keyName`、`tonality`。
- 正确选项 ID，以及可显示的和弦名称序列。
- 所有候选选项及其完整的实际音符/配位序列。
- 用于谱面渲染的音符拼写、低音与和弦位置。
- 题目实际播放的固定音符序列及必要的节奏参数。

公共页面只负责展示、播放、判题、记录和复盘；风格包负责提供音乐内容。具体代码可以使用适配层逐步接入现有爵士生成器和普通和弦生成器，不要求一次重写全部模块。

## 9. 答题与复盘页面

- 听题页沿用现有“调性名称居中 + 简洁播放舞台 + 和弦选项”布局。
- 页面上的风格名称与当前风格包一致，不显示其他风格的术语。
- 所有风格统一使用已确认的谱面优先答后复盘：正确与用户谱面对照、差异位置高亮、点击谱面或和弦试听，以及“下一题”。
- 复盘中显示的和弦标记、实际五线谱音符、播放音符必须来自同一份题目数据。
- 如果某个风格尚不能提供完整谱面与用户答案试听，则该包不可作为“已完成整合”上线。

## 10. 历史记录与兼容

- 新记录保存顶层模块 `chordProgression` 和所选 `stylePack`，并保留风格专属设置、正确答案、用户答案及实际配位的必要信息。
- 现有 `jazz` 记录展示为“和弦进行 · 爵士”，原有爵士语汇与配位统计继续可读。
- 现有 `progression` 记录展示为“旧版综合和弦”或等价历史名称，不得未经判断全部归类为流行或古典，因为旧热身库包含混合语汇。
- 不删除或覆盖浏览器本地已有记录；历史筛选与报告须兼容旧、新数据。

## 11. 异常情况

- 当前风格与设置无法生成足够的有效题目或干扰项时，在开始训练前给出明确提示，不得悄悄调用别的风格包补题。
- 某个包不支持某种专属设置时，隐藏或禁用该设置，不沿用上一个包的值参与出题。
- 切换风格后重新校验调性、语汇与配位组合；已开始的一轮训练不受设置页后续改动影响。
- 如果旧记录缺少 `stylePack`，按旧记录类型展示，不猜测其风格归属。
- 调性名称、和弦符号与谱面拼写冲突时，以实际发声音符为检查依据并阻止不一致题目进入训练。

## 12. 验收标准

1. 设置页只有一个顶层“和弦进行”入口，风格包为流行、爵士、古典三选一。
2. 选中一个包后，只显示其相关设置；开始训练后所有题目和选项均来自所选包。
3. 流行、爵士、古典使用各自一致的命名、和弦语汇、连接规则和配位；没有跨包术语或音响混入。
4. 各包均可完成配置、听题、选择、判题、谱面对照、分别试听和下一题的完整流程。
5. 重听题目与答后试听播放的音符，和答题时的音响及谱面一致。
6. 在用户选择的调式、调性、题量和专属设置边界内出题；设置不合法时给出可理解的提示。
7. 新历史可按风格包查看；旧爵士与旧综合和弦记录仍能正常显示，不被错误归类。
8. 手机与桌面端的风格切换、答题和谱面复盘均可操作。

## 13. 建议实施顺序与验收状态

1. 统一顶层入口、风格选择与配置快照。
2. 定义公共题目格式，把现有爵士生成器接入公共训练流程，确保播放和谱面能力不回退。
3. 从现有综合和弦及混合热身库中整理流行材料，建立流行包的题目和配位。
4. 建立古典包独立规则、题目和配位，并验证功能标记、转位与实际音响。
5. 完成历史兼容、跨包隔离和桌面/移动端完整流程验收。

当前状态：首期整合已实现，逻辑测试与桌面浏览器流程已通过；手机布局仍需在具体设备上复核。第 16 节的 SATB 与合奏音色属于新增待开发需求。

## 14. 本次实现范围

- 顶层只保留“和弦进行”，风格包单选。流行使用固定的四和弦循环与三和弦配位；爵士沿用原有语汇包、功能语法和钢琴配位；古典使用独立的终止与转位进行库。
- 古典包可单独开启重属、那不勒斯六和德国增六和弦；关闭后，这些和弦不会进入正确项或干扰项。流行包不抽取古典或爵士材料。
- 三包的每个选项在出题时即生成并保存实际 MIDI 配位；听题、复盘五线谱、正确答案及用户答案试听均使用该选项的固定配位。
- 新记录写入 `chordProgression` 与 `stylePack`，逐题保留正确与所选进行的实际配位。旧 `jazz` 和 `progression` 记录仍按原类型读取，旧综合和弦不推断风格。
- 流行与古典首期使用经规则列明的四和弦进行库，不提供任意长度或跨风格自由拼接。以上属于本期训练材料边界。

## 15. 古典进行的起点与终止多样性改进

### 背景与目标

首期古典进行库过度集中在 I／i 起步、V–I／V–i 收尾。用户即使没有听清中间和弦，也可能凭开头和结尾猜题。改进后，题目仍采用受控的四和弦句型，但要呈现不同的功能起点与终止感。

### 出题规则

- 按终止功能组织题库：正格终止（V–I／V–i）、半终止（停在 V）、阻碍终止（V–vi／V–VI）和变格终止（IV–I／iv–i）。
- 每个终止类别都需有大调和小调的合法进行；类别之间由随机选择决定，不根据用户成绩自动调整。
- 起点可以是主和弦、主和弦转位、下属功能或六级和弦；不得固定从 I／i 出发。
- 候选答案仍从同一调式和用户开启的古典语汇中选取，优先接近正确项；不能使用跨调式或被关闭的调外和弦凑选项。
- `I64／i64` 只在明确的终止四六语境中导向 V；`N6` 与 `Ger+6` 必须导向 V；`V/V` 必须先解决到 V。这些局部功能不能为了增加变化而随意改写。
- 为避免某个终止类别因模板数量较多而压倒其他类别，先随机选择可用终止类别，再从该类别中随机选具体进行；仍避免与上一题完全相同。

### 验收标准

- 大调和小调、无调外语汇时，均能生成四类终止；不再所有题目都从 I／i 开始或都以 V–I／V–i 结束。
- 仅选择某一种调外语汇时，正确项与所有选项均不出现其他未选调外和弦。
- 每条进行中的终止四六、重属、那不勒斯六与德国增六都保留合法解决。
- 四个选项保持相同和弦数量、可播放的实际配位与谱面音符；相同题目可复现并用于测试。

当前状态：已实现；大调、小调四类终止与调外语汇边界已通过自动测试。实际听感仍需在浏览器中试听复核。

## 16. 古典 SATB 配位与和弦合奏音色

### 16.1 背景与目标

目前古典包只有“低音 + 高音区三个紧密音符”的键盘式配位，无法练习四个独立声部的连接。吉他、萨克斯和小提琴音色播放整段和弦时，相邻和弦之间还会出现可察觉的短暂断音。用户希望古典包另有标准 SATB 配位，并将和弦训练中的单支萨克斯、单把小提琴改为真正由多件乐器构成的管乐与弦乐音色。

目标是在保留现有和声题目与爵士配位的前提下，让古典包可选择四声部写作，并让所有非钢琴和弦音色在等时拍点之间听起来连贯。音色、复盘谱面和实际发声必须依据同一份固定配位数据。

### 16.2 范围与非目标

- 本次覆盖和弦进行模块的流行、爵士、古典三包的播放衔接；SATB 生成和配置仅属于古典包。
- 和弦模块的音色选项为“钢琴 / 吉他 / 管乐 / 弦乐”。管乐和弦乐必须分别由不同乐器或声部采样组合形成，不能仅把现有独奏萨克斯或独奏小提琴改名。
- 音程辨认和旋律听写继续显示并使用当前独奏“萨克斯 / 小提琴”选项；其现有题目规则、独奏音色和历史记录不因本次改动而改写。
- 不新增人声合唱音色，不改变爵士既有的三种配位，也不为了加入 SATB 而改变古典包的和声语法、题目长度或终止类别。

### 16.3 用户流程与配置

```text
选择和弦进行 → 选择古典 → 选择键盘配位或 SATB 四声部
→ 选择钢琴、吉他、管乐或弦乐 → 开始训练
→ 听题、作答、查看同一配位下的谱面与试听
```

- 古典包的配位为单选，默认“键盘配位”，以保留当前听感；“SATB 四声部”是明确的第二种配位，不与键盘配位混用。
- 切换古典配位时，调式、调性、古典调外语汇设置保持原选择；开始训练后将配位与音色写入本轮配置快照，整轮题目和所有选项都使用所选配位。
- 从古典切到爵士或流行时隐藏古典配位设置；切回古典时恢复此前选择。爵士自己的配位选择不受影响。
- 和弦音色与独奏音色使用不同标识保存。切换训练模块时，显示该模块有效的音色选项并恢复上次有效选择；旧记录中的 `sax`、`violin` 继续按原独奏音色显示，不推断成管乐或弦乐。

### 16.4 古典 SATB 四声部规则

- 每个和弦恰有 S、A、T、B 四条可追踪的发声声部；三和弦按功能合理重复一个和弦音，不能靠添加不属于该和弦的音凑足四声部。七和弦及德国增六和弦按其实际结构与解决要求决定重复或省略，不得改变功能音。
- 声部按音高保持 `S ≥ A ≥ T ≥ B`，不交叉；相邻和弦不得无意交换声部身份。上三声部采用各自可唱的常规音域，S–A、A–T 间距原则上不超过八度；T–B 可更宽。超出音域、交叉或无法合法配位的候选题目应重选或在开始前报错，不能静默退回键盘配位。
- 相邻和弦优先保留共同音并用级进连接，其余声部尽量平稳移动；较大跳进须有音乐理由并控制后续走向。避免声部间平行纯五度、平行八度和明显的隐藏同向八度；不重复导音，导音及和弦七音按其功能解决。
- 原题的转位由最低声部 B 明确体现。终止四六、那不勒斯六、德国增六、重属和弦继续遵守第 15 节的局部解决规则；德国增六的增六度两端须按正确方向解决，不能只用等音拼写掩盖声部错误。
- 每个选项在出题时一次性确定四条声部的 MIDI 音高与记谱拼写，并在整题播放、单和弦试听、正确／我的答案复盘和历史记录中保持不变。谱面应清楚区分高音谱表上的 S/A 与低音谱表上的 T/B，完整显示四声部和转位低音。

### 16.5 和弦播放衔接

- 维持当前等时和弦起音节奏；解决断音时不靠推迟下一和弦。整段题目、重听、正确答案、我的答案和 A/B 对比中的连续和弦，使用一致的发声时序。
- 吉他允许自然拨弦衰减，但前一和弦尾音应延续到下一和弦起音附近，不产生人为静音。管乐与弦乐的持续音应在下一和弦起音时平顺换气、换弓或交接，必要时使用短暂重叠与释放包络，既避免可闻的数百毫秒空白，也避免长时间混响造成两个和弦难以分辨。
- 对保留音可选择持续或平滑交接；变化音按新和弦进入。单独试听一个和弦仍可正常收尾，A/B 两段之间原本用于辨别答案的停顿可以保留。
- 播放调度必须以预先确定的音符、声部、音色和拍点为准；多次重听不重新生成配位，也不因预加载或音色切换改变拍速。离线播放和首次采样加载仍须可用。

### 16.6 管乐与弦乐合奏音色

- “管乐”使用至少两种可辨认的管乐器采样或等效真实音源，按音域把高、中、低声部分配给合适乐器，例如长笛／双簧管、单簧管／圆号、巴松等；不得让一支萨克斯同时充当全部声部。
- “弦乐”使用有区别的高、中、低音弦乐器采样，例如小提琴、中提琴、大提琴，低音声部需要时使用低音提琴；不得把同一把独奏小提琴简单复制四次并标为合奏。
- 同一题始终使用同一套乐器分配。SATB 模式按 S/A/T/B 分配，键盘式及其他风格按实际声部音域分配；所有采样的发声时刻、力度、释放和声像需校准，避免低音被盖住、音量突变或叠加削波。
- 必须内置或可离线使用所需音源。缺少必要音源时，明确提示该合奏音色不可用或使用如实标注的备用方案；不能悄悄退回单支萨克斯／小提琴却继续显示“管乐／弦乐”。

### 16.7 异常与验收标准

1. 古典包能在“键盘配位 / SATB 四声部”间切换；同一道和声规则在 SATB 下的每个选项都恰有四条有身份的声部，转位低音、功能音、谱面和试听一致。爵士配位及流行包不受古典选择影响。
2. 对大调、小调、各终止类别及启用的调外语汇，自动检查 SATB 音域、声部次序、重复音、平行五／八度、导音与七音解决；无法合法生成时给出明确错误，不提供伪 SATB 或键盘回退。
3. 钢琴、吉他、管乐、弦乐各完成一段至少四和弦的听题与复盘试听。吉他、管乐、弦乐在相邻拍点间没有明显静音断层，也没有过长的和弦重叠；重复播放的拍点和音高一致。用实际音频录制／波形检查并辅以听感复核。
4. 管乐、弦乐试听时可识别不同音域的乐器层，实际使用至少两种不同音源；音量平衡、低音可闻且不削波。断网后重新打开本地应用仍能播放。
5. 和弦模块显示“管乐 / 弦乐”，音程和旋律模块仍显示“萨克斯 / 小提琴”；新旧训练记录均显示当时真实使用的音色与配位，切换模块或风格后不串用配置。
6. 桌面与手机端均能完成选择、整段播放、单和弦试听和谱面复盘。

当前状态：已实现古典配位切换、四声部生成与复盘谱面；已加入本地管乐／弦乐分声部采样，并为非钢琴和弦延长发声至下一拍点附近。所有调性和四种终止的 SATB 声部约束已通过自动测试，浏览器内已验证配置、答后谱面和单和弦试听。仍需使用录音波形与人工听感，对不同设备上的衔接和各乐器响度作最终校准。

## 17. 和弦标记、流行扩展语汇与低音下限

### 17.1 背景、目标和范围

和弦进行训练目前只用字母音高显示选项；流行包只有调内三和弦；部分配位的低音低于 G2，使低音音色成为过强的提示。本次让玩家选择罗马数字或字母音高标记，在流行包内逐项扩展和弦语汇，并使流行、爵士、古典各配位的实际最低音均不低于 G2（MIDI 43）。

标记方式只改变答案按钮和复盘和弦标签，调性、题目、实际音高、谱面拼写和播放不随标记切换而改变。流行扩展包只影响流行风格；爵士、古典既有语汇不因流行包选择而变化。音程和旋律模块不使用此设置。

### 17.2 用户流程与功能要求

选择“和弦进行”后，可在“和弦记法”下二选一：**和弦符号**（默认，例如 C–Am–F–G）或**罗马数字分析**（例如 I–vi–IV–V）。两个选项都以完整卡片作为点击区域，并清楚显示当前选择，不能出现可见的大块区域无法点击的情况。该设置在流行、爵士、古典三种风格的整轮训练内固定，答案选项和复盘轨道使用同一标记方式；调性中心仍正常显示。和弦符号须体现根音、和弦性质以及转位斜杠低音。**流行包的转位采用斜杠标注**：和弦符号用实际低音音名，例如 C/E；罗马数字分析用相对当前主音的阿拉伯数字级数，例如 C 大调的 I/3、小调的 i/3，变化音相对当前调式加升降标记。不能显示 I/E 或 I⁶。**古典包保留数字低音**，例如 I⁶、I⁶₄。古典德国增六用根音加“+6”标记，避免误写为属七和弦。

选择流行风格后显示可叠加的语汇包：

1. **调内三和弦（必选）**：保留现有大调、小调四和弦循环；不可取消。
2. **挂留和弦**：sus4 及 V7sus4；挂留结构在所属功能位置替代原三和弦，小调也可使用属七挂留。
3. **七和弦**：大七、小七、属七、半减七等与原调式及功能相符的替代；小调 V7 使用和声小调导音。
4. **Add／6·9 和弦**：在原有大三 add2、小三 add4 之外，加入大三 add6、完整五声音的 6/9，以及小三 add2、add4 等；和弦符号、罗马标记、谱面及播放须包含对应的附加音，6/9 不能省略六度或九度。
5. **转位和弦**：在谱面与播放中使用转位低音；字母标记显示斜杠低音。
6. **调式借用**：取平行调或常见平行调式的色彩。大调可用 iv、♭VI、♭VII、♭III；小调可用 IV、I、ii、V。原“借用下属色彩”并入本包，不再单列；借用音在谱面正确拼写。
7. **副属和弦（Secondary Dominant）**：与古典风格的“重属”设置分开。在流行进行中加入 V7/V、V7/vi、V7/IV、V7/ii 等，或小调对应的 V7/III、V7/VI、V7/iv、V7/v；副属七和弦必须紧邻并解决到斜杠后的目标和弦，不能出现在句末或只作无目标的替换。关闭本包后，流行题目与所有干扰项都不出现这些和弦；古典的重属规则保持原样。

开启扩展包时系统沿用既有流行进行的位置与连接，仅在合适功能位替换和弦；正确答案与干扰项都只能使用已选包。取消包后新题不再出现该包独有和弦。每个选项仍是独立的完整进行，和弦标签、音响与 VexFlow 谱面须对应。

本次调整不改变爵士与古典语汇，也不把流行语汇包的勾选状态延伸到其他风格。无合适目标和弦时不生成副属进行；不能为了凑足题量而加入未开启的包。历史记录中的旧包标识继续保留为历史数据，新题只使用当前语汇包名称。

### 17.3 音域、异常与验收

- 每个和弦的所有实际发声音（包括古典 SATB 男低音、键盘左手及爵士非 rootless 低音）均须 ≥ G2；rootless 也要检查全部实际音符。不得只移动记谱标签而保留原低音播放。
- 扩展包内容不足以组成合法题目时给出明确错误，不回退到未选语汇。旧历史记录保持可读，新增记录保存标记方式与流行包选择。
- 自动覆盖大／小调、十二个调性、各配位、各流行包开关，验证四个独立选项、包边界、记谱音高与播放音高、最低音及显示标签。浏览器手动验证设置、答题、复盘和窄屏布局。

当前状态：已实现记法切换、流行语汇包和所有和弦配位的 G2 下限。自动测试覆盖大／小调、十二调、三种爵士配位及古典 SATB；浏览器已验证三种风格的配置、记法选项和答后谱面。记法控件已改为完整可点击卡片，卡片边缘点击切换和右侧配置摘要同步已验证。不同播放设备上的实际听感仍可继续由人工试听确认。
