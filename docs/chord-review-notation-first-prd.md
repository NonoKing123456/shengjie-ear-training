# 和弦答题反馈：谱面优先改版需求

## 1. 设计结论

和弦答题后的反馈页面以**正确答案与用户答案的双层五线谱对照**为核心。谱面是用户复盘和试听的主要入口，不再将播放功能拆成多组按钮，也不再将和弦逐个放进大卡片。

页面主流程应为：

```text
知道错在哪里 → 看正确与用户谱面 → 点击谱面试听 → 下一题
```

## 2. 目标

- 让五线谱成为答后反馈的主要视觉内容。
- 在不使用左侧文字标签列的情况下，清楚区分正确答案与用户答案。
- 让用户直接点击谱面或和弦完成试听。
- 大幅减少按钮数量和信息噪音。
- 让用户在单屏内完成错误定位、对比试听和进入下一题。

## 3. 页面结构

### 3.1 顶部摘要

顶部保留题目标题、训练进度和一行简洁的错误结论：

```text
答错了 · 第 2 个和弦不同
```

摘要下方并列展示两条紧凑的和弦进行文本：

```text
Cmaj7 – Am7 – D7 – Gmaj7  |  Cmaj7 – Bm7 – D7 – Gmaj7
```

其中：

- 正确进行使用绿色。
- 用户进行使用珊瑚红色。
- 文本仅用于快速确认，不应抢占谱面空间。

### 3.2 双层大五线谱（页面主体）

在摘要下方展示两条上下对齐的整段五线谱：

- 上方：正确答案的完整进行。
- 下方：用户答案的完整进行。
- 每条进行由一张横向、连续的双谱表呈现，不再拆成多个独立小卡片。
- 所有和弦位置在上下两行严格横向对齐。
- 和弦符号显示在各自和弦位置上方。
- 五线谱区域应占反馈卡片约 60% 以上的视觉高度与宽度。

不显示“正确答案”“我的答案”等左侧文字列，避免压缩谱面。用以下视觉信号区分两行：

- 正确行最左侧使用细绿色竖线；和弦符号使用绿色。
- 用户行最左侧使用细珊瑚红竖线；和弦符号使用珊瑚红色。

### 3.3 差异高亮

- 系统按和弦位置比较正确答案和用户答案。
- 所有不同位置必须在上下两条谱面中同步高亮。
- 正确行的差异和弦使用淡绿色半透明背景。
- 用户行的差异和弦使用淡珊瑚红半透明背景。
- 高亮区域应覆盖该和弦的符号与对应谱面区域，方便垂直比较。
- 若有多个差异，全部高亮；摘要可默认提示第一个差异位置。

## 4. 谱面交互与播放

不在谱面下方保留“播放正确答案”“播放我的答案”“A/B 对比”“再听一次题目”等独立按钮。

### 4.1 直接播放

- 点击正确答案谱面的空白区域：播放完整正确进行。
- 点击用户答案谱面的空白区域：播放完整用户进行。
- 点击任一和弦区域：仅播放该位置的和弦。
- 鼠标悬停或触屏首次使用时，给出轻量提示：`点击和弦试听，点击谱面播放整段`。

### 4.2 播放状态

- 播放整段时，当前和弦位置随播放进度移动高亮。
- 播放单个和弦时，仅高亮被点击的和弦区域。
- 同一时间只能有一个播放任务；新播放请求应停止当前任务。
- 用户点击“下一题”时，停止所有播放。

### 4.3 对比试听

用户可依次点击正确谱面和用户谱面完成手动对比。若保留快捷入口，只允许使用一个极弱化的 `A ↔ B` 图标，不得恢复为显眼的大按钮组。

## 5. 操作区

反馈区底部只保留一个主要按钮：

```text
下一题 →
```

要求：

- 位于右下角，使用当前产品的荧光绿色主按钮样式。
- 为反馈区唯一强视觉按钮。
- 在桌面端固定为右对齐；移动端可占满一行。

## 6. 视觉原则

- 减少边框、分割线、嵌套卡片和重复说明。
- 不要把每项操作都设计成按钮。
- 正确、错误、播放中三种状态使用固定且一致的颜色语义。
- 相同和弦保持低对比度；差异和弦才突出显示。
- 谱面必须可读，不能为了压缩高度而缩小到难以辨认。
- 页面保持安静、清晰和音乐学习工具的质感，避免形成密集的控制面板。

## 7. 响应式要求

- 桌面端：优先完整展示整段横向双谱表。
- 窄屏：谱面可在容器内横向滚动，不允许压缩音符、和弦符号或错误高亮至不可读。
- 移动端仍保持“正确行在上、用户行在下”的顺序。
- “下一题”始终容易找到，点击区域不小于现有主按钮。

## 8. 验收标准

- 用户答错后，第一屏可同时看到正确进行、用户进行和两条大五线谱。
- 不存在左侧“正确答案 / 我的答案”的文字标签列。
- 用户可以仅通过颜色与左侧细竖线识别两条谱面的身份。
- 用户能看到所有差异和弦的上下对应高亮。
- 用户点击任意谱面行可播放整段，点击任意和弦可单独试听。
- 播放中当前和弦有明确的同步高亮。
- 反馈区域底部没有一组播放按钮，只保留“下一题”作为主按钮。
- 在桌面端，五线谱是反馈区域最显眼、占用面积最大的部分。
- 现有题目生成、voicing、音频调度、训练统计和历史记录不受影响。

## 9. 实现提示

优先复用现有爵士复盘的真实 voicing 数据、五线谱渲染能力和播放调度。实现重点是调整反馈内容的 DOM 结构、谱面布局、差异索引映射与点击区域；不要为本次改版改写题目生成或音频采样逻辑。
