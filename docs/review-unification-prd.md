# 三类训练的复盘交互统一

## 背景与目标

旋律听写在提交后只在复盘内容超出当前视口时定位一次，谱面本身承担试听入口。音程辨认仍使用手绘谱面与多组重复按钮；和弦进行复盘又隐藏了题目上方的调性标题。三类训练的复盘体验需要统一。

## 范围与流程

- 音程、和弦进行和旋律听写在提交答案后都进入独立复盘状态；答对时只展示一份谱面，答错时展示正确与我的两份谱面，保留必要的结果说明和唯一强操作“下一题”。
- 提交后下一帧检查复盘内容是否完整处于当前视口。已完整可见时保持滚动位置；否则只执行一次定位。调性标题与谱面能同时放下时，从调性标题开始展示；放不下时优先定位谱面复盘区。输入、修改、删除或试听均不触发该定位。
- 旋律复盘移除重听题目按钮。旋律与和弦页面的调性标题保持水平居中，和弦复盘保留该大标题。上方题目身份信息不因提交而删除。
- 音程复盘改用项目现有 VexFlow，音高、升降号、谱号和谱线由同一渲染器输出。顺序发声时，每个音有宽大的谱面点击区；点击该区试听对应音，点击谱面其他区域播放整段。同时发声的两个音按和声音程记谱，点击谱面播放整个音程。键盘操作可用 Enter／空格激活谱面。
- 删除音程复盘中的重听、单音和 A/B 按钮；只保留谱面交互与“下一题”。和弦复盘继续用现有和弦区与整行谱面播放方式。

## 异常与验收

- 音程跨越高低音域时，谱号及辅助线可读，记谱音高与实际播放 MIDI 一致；不能因为答错而把我的答案错画成正确音高。
- 三类复盘各检查答对、答错、手机窄屏、较矮视口、鼠标及键盘试听；提交后只定位一次，试听不改滚动位置。
- “下一题”始终是复盘区唯一强按钮。谱面播放时对应区域显示高亮，完整播放和单音播放能正确区分。
- 音程复盘依次发声时只高亮当前音符的点击区；只有两个音符同时响时，整张谱面的矩形区域才随播放高亮。
- 音程与旋律复盘的单音高亮统一为透明底和同色细边框；音符发声时轻微发光，并在实际音符播放时长内逐渐减弱。正确答案用绿色，我的答案用珊瑚红。同时发声时的整张谱面高亮也随声音减弱。
- 和声进行复盘中，差异和弦保留绿色／珊瑚红底色，播放时只让外侧线框发光并随声音渐弱。上方和弦符号沿用相同线框动画；相邻和弦声音重叠时，各自的高亮按实际持续时间结束，整行谱面不一起发光。旋律听写的差异音符也只保留底色，去掉静态线框，播放时再显示同款动态线框。
- 和声进行复盘的谱面和弦点击区在鼠标悬停或键盘聚焦时显示对应的大矩形：普通和弦用浅绿／浅红半透明底色，差异和弦保持原有较明显的底色；边框提示与单个和弦播放区域一致。
- 和声进行复盘中，悬停在单个和弦框以外的谱面空白处或键盘聚焦整行时，显示覆盖该答案整张双层五线谱的大矩形和整段播放提示；悬停单个和弦时只显示该和弦框，不叠加整行提示。
- 和声进行的整谱悬停矩形置于左侧状态竖线右侧，与竖线保持和音程、旋律复盘一致的 13px 空隙；矩形上下边缘与竖线的内缩保持一致，不让竖线落在矩形内部。谱面容器不显示额外的常驻边框，以免把两行谱面和竖线重新包起来。
- 音程、和声进行与旋律的连续谱面（包括旋律输入谱）不绘制每个谱表默认的起止小节线，避免出现额外的黑色竖线；保留五条谱线、谱号和音符符干。
- 三类复盘的单音／单和弦命中区域共用浅色填充、细线框和随声音衰减的轻微发光；正确答案为绿、我的答案为珊瑚红。音程单音悬停也必须有浅色内部填充，线框不比旋律与和弦更粗。
- 单个和弦的可点击区域仍覆盖靠近上下边缘的音符，但视觉框上下等距内缩，与整段谱面悬停框的上、下边缘都留出可见间隙；差异和弦的底色保留在内缩后的视觉框中。

当前状态：已实现。自动测试已覆盖音程记谱的实际 MIDI 音高与临时升降号范围；浏览器已核对音程顺序／同时发声的答错复盘、和弦调性标题、旋律复盘重听入口移除，以及谱面点击后滚动位置不变。窄屏 390 × 780 下已检查音程复盘布局。
